# SupplyShield

## Purpose
SupplyShield is a CAP-based side-by-side extension for material-shortage detection, substitute-material recommendation, and approval management.

## Architecture summary
- SAP CAP with Node.js
- CDS for domain and service modeling
- OData V4 service exposure
- SQLite for local development
- SAP HANA Cloud for production

## Local prerequisites
- SAP Business Application Studio
- Node.js and npm
- CAP tools installed via the local project dependencies
